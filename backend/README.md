# Backend App

This directory contains the FastAPI backend implementation for open-health-server.

## Local Run

Install dependencies in a virtual environment, then run:

```bash
uvicorn backend.app.main:app --reload
```

Useful endpoints:

- `GET /health`
- `GET /version`

## Migrations

Alembic is configured at the repository root.

```bash
.venv/bin/alembic upgrade head
```

The migration files live in [migrations](migrations/README.md).

## Models

The SQLAlchemy model layer lives in [app/models.py](app/models.py) and mirrors Schema V1. Alembic imports these models in [migrations/env.py](migrations/env.py) so future autogenerated migrations can compare `Base.metadata` against the live database.

## Seed Catalog

Load or refresh the seed metric catalog with:

```bash
.venv/bin/python -m backend.app.commands.seed_catalog
```

The command reads [../catalog/seed-metric-catalog-v1.json](../catalog/seed-metric-catalog-v1.json), validates it, and upserts rows into `metric_definitions`.

For a full handoff of the current implementation state, see [Current Implementation State](../docs/planning/current-implementation-state.md).

## Docker Compose

From the repository root:

```bash
docker compose up --build
```

The API is exposed on `http://localhost:8000` and TimescaleDB/PostgreSQL is exposed on `localhost:5433`.
